Instruction Set Reference

          
Minimalist 256B VM · Zero Exceptions · No Implicit Side Effects

        

        
      

      

        

          Design Philosophy: There are no runtime errors or exceptions. Unknown opcodes are silently skipped; invalid jump labels fall back to line 0. Memory is never implicitly zero-filled on reset—use Reset PC to re-run code against existing cache, or Clear RAM to wipe memory explicitly.
        


        

          
            

              Opcode
              Behavior
            

          
          
            
load NSet acc = N (defaults to 0 if invalid).

            
set NSet counter = N mod 256.

            
store [N]Write N (or acc if omitted) to RAM[counter].

            
add / subacc = acc ± RAM[counter].

            
inc / cincIncrement counter (wraps mod 256).

            
dec / cdecDecrement counter (wraps mod 256).

            
printOutput acc followed by a newline.

            
stores TEXTWrite min(acc, len(TEXT)) ASCII codes to RAM starting at counter.

            
printsRead acc bytes starting at counter and print as ASCII string.

            
inputsRead from Input Buffer, writing min(acc, len(input)) ASCII codes at counter.

            
&labelDefine a jump/call target label.

            
jmp LABELUnconditionally jump pc to LABEL (or 0 if undefined).

            
jpnz LABELIf counter ≠ 0, jump pc to LABEL (or 0).

            
call LABELStore pc + 1 at RAM[counter], increment counter, jump to LABEL.

            
retDecrement counter and set pc = RAM[counter].
